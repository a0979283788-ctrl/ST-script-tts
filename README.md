# 声林 · 剧本分段版（ST-sound-forest-script v2.3.0）

在 [声林 TTS v2.2.4](https://github.com/lynn33-2728/ST-sound-forest-TTS) **原插件本体**上改造：保留声林全部功能与界面（4 引擎 / 火山复刻 / 多人角色音色 / 缓存 / 播放条），新增 **🎬 剧本朗读模式**。

## 剧本朗读模式做什么

一条「旁白 + 多角色台词」的回复，自动拆成**多个独立语音段**，每段一条可单独点击的语音条，按顺序连读：

- `旁白` → 专用旁白音色（可选，默认当前引擎默认音色）
- `角色A「…」` → 按**「多人角色音色」表**匹配 A 的音色
- `角色B「…」` → 匹配 B 的音色
- 未绑名字的台词 → 默认音色
- 旁白里的（动作描写）可剥离不读
- 手动点任意一条即中断自动连读，单条播放；重听走缓存不重复扣费
- 关闭开关则 **100% 回到声林原版整条朗读**

## 安装（覆盖安装即可）

酒馆 → 扩展管理 → 安装扩展程序 → 输入：

```
https://github.com/a0979283788-ctrl/ST-script-tts
```

已装过原版声林？直接再装一次即可覆盖（文件夹同名 `ST-sound-forest-TTS`）。或下载仓库根目录的 `ST-sound-forest-script-v2.3.0.zip` 本地安装。

## 使用

1. 火山引擎页填 AppID / Access Token，测试连接变绿（或用硅基流动 / MiniMax / MOSS，剧本模式跟随当前引擎）
2. 展开设置里的 **「🎬 剧本朗读模式」** → 勾选启用 → 选旁白音色
3. 在 **「多人角色音色」** 表里给每个角色绑音色（原插件功能，直接复用）
4. 台词用 `「」`，**台词前一行写角色名**识别最准：

```
南华仙子侧过脸来。
南华「你……且慢些。」
青衣「慢不了了。」
```
