# 剧本多角色语音 ST-Script-TTS
SillyTavern 扩展：把一条「旁白 + 多角色台词」回复拆成独立语音单元——旁白一个音色、角色 A/B 各自绑定音色，逐条独立语音条并自动连读。引擎：火山引擎豆包语音（经酒馆 /proxy 中转）。

## 安装
扩展管理 → 安装扩展程序 → 输入本仓库地址：
`https://github.com/a0979283788-ctrl/ST-script-tts`
安装后在扩展列表勾选启用。

## 使用
1. 面板填火山 AppID / Access Key（或借用「声林」扩展凭证），点“测试连接”。
2. 选旁白音色；添加角色并为每个名字选音色。
3. 台词用「」，台词前一行写角色名识别最准：
```
南华仙子侧过脸来。
南华「你……且慢些。」
青衣「慢不了了。」
```
新回复生成后会按顺序自动连读；点任意一条单独播放并中断连读。重听走缓存不重复扣费。
